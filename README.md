AI Phishing Trainer

This is a simple cybersecurity training project built using HTML, CSS, and JavaScript.

The program shows sample emails and asks users to identify whether they are safe or phishing emails. Users receive instant feedback and can track their score while practicing.

Features

- Identify phishing and safe emails
- Score tracking

Technologies Used

- HTML
- CSS
- JavaScript

Purpose

I built this project to learn basic web development and improve my understanding of phishing attacks and cybersecurity awareness.
